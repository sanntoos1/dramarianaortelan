# Dra. Mariana Ortelan — Landing Page

Landing page responsiva em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html` — estrutura e conteúdo da página
- `styles.css` — identidade visual, responsividade, hover e animações
- `script.js` — menu mobile e animações de entrada por scroll
- `assets/dra-mariana-hero.png` — imagem principal da Dra. Mariana

## Personalização rápida
Os principais links de WhatsApp, Instagram, telefone e endereço estão no `index.html`.

A página não depende de framework ou build step. Basta abrir `index.html` ou publicar a pasta em qualquer hospedagem estática.
